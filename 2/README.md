# Ziad Arafat — Project Management Portfolio v2

A bilingual English/Arabic project-management portfolio with light/dark themes.

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Included
- `index.html` — content and layout
- `styles.css` — responsive design, light/dark themes, RTL support, animation
- `script.js` — language switcher, theme persistence, scroll reveals, interactions
- `assets/ziad-arafat.jpg` — profile image
- `assets/Ziad_Arafat_Project_Manager_CV.pdf` — downloadable CV

Content is based on the provided CV, plus the user-provided PMP / Lean Six Sigma / Odoo ERP project-owner additions.
